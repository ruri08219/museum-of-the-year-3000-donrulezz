A one-line museum label from the year 3000 for a CAPTCHA — the "proof of humanity" ritual of 2024.

## Entry

> Proof of Humanity, 2024. To enter, visitors named traffic lights for a machine. The machine believed them.

## How it works

`main.py` (Python standard library only) writes exactly one line, at most 200 characters with no trailing newline, to `/output/entry.txt`. It validates the line first: 1–200 characters, a single line, no leading or trailing whitespace, no control characters, no lone surrogates — and verifies the written file byte-for-byte.
